# Project Layout

This project is a single-file web app. Keep `index.html` at the repository root so GitHub Pages can serve it. The other root-level project files are `AGENTS.md`, `spec.md`, and `prompts.md`.

Use the numbered folders for supporting files:

- `00_planning/` — planning notes and sketches.
- `01_data/` — data files.
- `02_validation/` — hand calculations and test cases.
- `03_output/` — screenshots and exported results.

Save every new file in the appropriate root location or numbered folder. Keep the root limited to the four named project files and repository configuration files.

After each request, add an entry to `prompts.md` describing what was asked, what changed, and whether it worked.
